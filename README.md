# JM Motors — Web Base (Next.js + Tailwind)

Proyecto base listo para abrir en VS Code y comenzar.

## Requisitos
- Node.js 18+ (ideal 20+)

## Instalación
```bash
npm install
npm run dev
```

Abre: http://localhost:3000

## Branding
Los colores están en `app/globals.css` como variables CSS (bg, surface, brand, etc.).
